# AmenityList

What the home offers, with icons, including notable absences.

- Props: `items` (`[{icon, label, available}]`; `available: false` strikes it through), `columns` (1 · 2 · 3), `limit` (show N plus a “Show all” Button), `onShowAll`.
- Lead with what renters filter on: laundry, AC, parking, pets, furnished.
