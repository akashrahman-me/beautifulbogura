# StickyActionBar

The bottom bar on phone and tablet listing pages: price plus the primary action. Hidden from lg.

- Props: `price`, `currency`, `period`, `sub` (e.g. “1 Mar · 12 months”), `actionLabel`, `variant`, `onAction`, `position` (`fixed` · `static`), `hideOnDesktop`.
- Tapping the action opens the BookingPanel in a Modal sheet.
