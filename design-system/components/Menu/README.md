# Menu

A dropdown of actions or a single-choice list, anchored to a trigger.

- Props: `items` (`{label, icon, onSelect, danger, checked}` or `{divider: true}`), `label` (default trigger text), `trigger` (your own Button or IconButton), `align` (`end` · `start`), `defaultOpen`.
- Use for the account menu, sort order and listing row actions. Closes on select, Esc and outside click.
