# IconButton

A round, icon-only button for compact toolbars, card overlays and headers.

- Props: `icon`, `label` (required — becomes `aria-label` and the tooltip), `variant` (`ghost` · `secondary` · `primary` · `overlay`), `size` (`sm` 36px · `md` 44px), `pressed` (toggle state), `dot` (unread indicator).
- `overlay` sits on photos (share, back); `secondary` for filters and steppers; `ghost` in the Navbar.
- If the action needs words to be understood, use Button instead.
