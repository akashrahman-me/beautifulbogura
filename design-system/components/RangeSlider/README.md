# RangeSlider

A two-thumb slider for a min–max range, usually the price filter.

- Props: `label`, `min`, `max`, `step`, `value` / `defaultValue` (`[lo, hi]`), `onChange`, `currency`, `format(n)`, `maxPlus` (adds “+” at the top of the range).
- Pair with two TextFields for exact entry in the filter sheet.
