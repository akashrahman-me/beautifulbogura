# ListingGrid

The responsive grid for PropertyCards and other repeated cards.

- Props: `columns` (3 default · 4 adds a fourth column at xl), `min` (switch to an auto-fill grid with this minimum card width in px), `as`.
- 1 column on phones, 2 from sm (640), 3 from lg (1024), 4 from xl (1280) when `columns={4}`.
