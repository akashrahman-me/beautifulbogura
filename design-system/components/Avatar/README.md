# Avatar

A person's photo or initials, with an optional verified tick.

- Props: `name` (used for initials and alt text), `src`, `size` (`xs` 24 · `sm` 32 · `md` 44 · `lg` 64 · `xl` 96), `verified`.
- `sm` in the Navbar and message headers, `md` in reviews, `lg` in HostCard, `xl` on profiles.
- Stack several with `.ers-avatars` for co-applicants or shared households.
