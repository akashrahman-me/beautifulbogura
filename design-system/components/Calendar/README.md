# Calendar

A month view for picking a move-in or viewing date, with unavailable days struck through.

- Props: `month` (`'YYYY-MM'`), `value` / `defaultValue` (`'YYYY-MM-DD'`), `onChange`, `unavailable` (array of ISO dates), `minDate`, `today`, `locale`, `legend`.
- Weeks start on Monday. Use inside a Modal sheet on mobile and a Menu-style popover from md.
