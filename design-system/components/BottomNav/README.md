# BottomNav

The phone and tablet tab bar for the five top destinations; hidden from lg, where the Navbar takes over.

- Props: `items` (`{icon, label, href, active, badge}`), `position` (`fixed` default · `static`), `hideOnDesktop` (default true).
- Keep to five items or fewer; labels one word. Pad page content by `bottomnav-height` so nothing hides behind it.
