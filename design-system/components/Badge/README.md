# Badge

A short status or attribute label; pair status colour with an icon or a word — never colour alone.

- Props: `tone` (`neutral` · `brand` · `accent` · `success` · `warning` · `danger` · `info`), `variant` (`soft` default · `solid` on photos), `icon`, `size` (`md` · `lg`).
- Vocabulary: success = Verified, Approved, Paid · warning = Pending, Expires soon · danger = Overdue, Rejected · accent = New, Price drop, Deal · brand = Featured, Instant apply.
- One to two words. Use `solid` only over imagery (PropertyCard tags).
