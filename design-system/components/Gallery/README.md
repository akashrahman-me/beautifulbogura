# Gallery

The listing photo viewer at the top of the detail page.

- Props: `images` (`[{src, alt, kind}]`), `total` (if more exist than passed), `onOpen(index)` (open the full-screen viewer).
- Phones: edge-to-edge swipeable carousel with a “1 / 18” counter. From md: a mosaic of one large and four small photos with “Show all photos”.
- Write alt text that describes the room: “Living room with balcony doors”.
