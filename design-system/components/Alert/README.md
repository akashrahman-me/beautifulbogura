# Alert

An inline message about the page or a task, in one of five tones.

- Props: `tone` (`info` · `success` · `warning` · `danger` · `brand`), `title`, `children`, `icon`, `action` (a Button), `onDismiss`.
- Danger alerts are announced (`role="alert"`). Lead with the outcome, then the fix: “Your ID couldn't be verified. Upload a clearer photo.”
