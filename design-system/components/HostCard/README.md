# HostCard

Who rents the home: landlord or agency identity, trust signals and contact actions.

- Props: `name`, `avatar`, `verified`, `role` (Landlord, Property manager, Agency), `joined`, `responseRate`, `responseTime`, `listings`, `children` (short bio), `onContact`, `onCall` (pass `null` to hide).
- Only show “ID verified” after real verification. Keep the bio to two lines.
