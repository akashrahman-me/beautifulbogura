# RadioGroup

One choice from a small visible set, as a list or as selectable cards.

- Props: `label` (legend), `options` (`{value, label, description}`), `value` / `defaultValue`, `onChange`, `variant` (`list` · `cards`), `name`.
- Use `cards` for meaningful choices with a price or explanation (lease length, plan tier). Cards stack on mobile and sit side-by-side from sm.
