# SectionHeader

The heading block that opens a page section: optional overline, display-face title, description and a right-aligned action.

- Props: `title`, `overline`, `description`, `action` (a Button or link), `align` (`start` · `center`), `as` (heading level, default `h2`).
- Title is 26px on phones, 32px from md, in the display face.
