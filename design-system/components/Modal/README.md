# Modal

A focused task over the page: a bottom sheet on phones, a centred dialog from md.

- Props: `open`, `onClose` (Esc, scrim click and the close button), `title`, `children`, `footer`, `size` (`sm` 420 · `md` 560 · `lg` 760).
- Use for filters, the booking flow on mobile, confirmations and photo viewers. Footer: secondary action left (“Clear all”), primary right (“Show 248 homes”).
- The consumer manages focus return and body scroll lock.
