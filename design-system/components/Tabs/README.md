# Tabs

Switches between sections of the same page — listing details, dashboard views.

- Props: `items` (`{value, label, icon, count}`), `value` / `defaultValue`, `onChange`, `variant` (`underline` default · `pill`), `label`.
- Scrolls horizontally on phones; keep labels to one or two words.
- `pill` for category filters above a grid (Apartments · Houses · Rooms).
